# Pinehollow pro-shop furniture asset record

All 120 furniture models in this directory are original procedural Blender work
created for Golf Flipper by `tools/blender/build_pro_shop_furniture.py` and
`tools/blender/build_clothing_racks.py`.

- External assets: none
- External textures: none
- Source references: project-owned boards in `Designs/ClubHouse` and
  `Designs/Clothing_Racks`
- Materials: original solid-color and script-generated stylized PBR materials
- Editable source: category libraries plus one production `.blend` per authored
  clothing-rack tier in `source/clothing-racks/`
- Runtime exports: `vendor/models/pro_shop_furniture/`
- Preview renders: `previews/`

No raw Tripo, Poly Haven, Sketchfab, generated, or third-party asset is modified
or redistributed by this library.

## Clothing racks (2026-07-21)

The Basic, Standard, Premium, High-End, and Luxury clothing racks are original
project-owned geometry generated by `tools/blender/build_clothing_racks.py` from
the five immutable project references in `Designs/Clothing_Racks/`. Their oak,
walnut, dark-walnut, and charcoal-metal maps are generated locally by that same
script. No downloaded model, marketplace asset, external texture, generated
image, or third-party artwork is incorporated. Exact sources, runtime exports,
references, dimensions, LOD statistics, nodes, textures, and previews are
enumerated in `clothing-racks-manifest.json`.
