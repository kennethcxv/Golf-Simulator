## Shared tier language

1. **Municipal / Value** — compact utility steel, open construction, no integrated lighting.
2. **Suburban / Retail** — finished charcoal frame, natural-oak shelf or base, larger capacity.
3. **Lodge / Crafted** — thicker frames, oak custom work, brass accents, more shelves and bays.
4. **Resort / Boutique** — walnut casework, fitted panels, restrained warm lighting, larger footprint.
5. **Private Club / Luxury** — built-in proportions, walnut and cream millwork, brass trim, multiple warm light strips, drawers/plinths/crown moulding, and the highest capacity.

Every one of the 18 requested families is authored in all five tiers. The source
and exported GLB retain the reference hashes and this tier identity as custom
properties for traceability.
